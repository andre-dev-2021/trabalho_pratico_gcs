# Planejamento

## Itens de Configuração

- Código
- PLANEJAMENTO.md (este arquivo)
- README

## Convenção de nomeação

- Nomes de arquivos em minúsculas e separados por hífen. Ex: `nome-arquivo.txt`
- Branches devem ser nomeadas no formato `tipo/descricao-curta`. Ex: `feature/pagina-login`.

## Versionamento

- Utilizar padrão `MAJOR.MINOR.PATCH`.
- `v1.0`: primeira versão.
- `v1.1`: nova função compatível.
- `v2.0`: mudança grande.

## Convenção de commits

- Utilizar conventional commits. Ex: `feat: botao de 'cancelar' adicionado`.

## Politica de Branching

- Um por tarefa.
- Um revisor deve avaliar antes de cada merge.

## Backup e Recuperação

- As tags marcam os pontos de recuperação (baselines).
