# Árvore Binária de Busca

Projeto simples em Python que implementa uma árvore binária de busca. Permite inserir valores, verificar se um valor existe, listar os valores em ordem crescente e obter o menor valor armazenado.

## Como executar

Requer Python 3. Execute na pasta do projeto:

```bash
python3 main.py
```

O programa cria uma árvore de exemplo e exibe seus valores ordenados, além de testar buscas por valores existentes e inexistentes.

## Arquivos

- `arvore.py`: implementação da árvore e de seus nós.
- `main.py`: exemplo de uso.
